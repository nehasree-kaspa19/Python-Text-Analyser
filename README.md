
# Python Text Analyzer 🔍

A simple Python program that analyzes text and provides useful statistics.

## Features
- Counts total words
- Counts total characters
- Counts sentences
- Calculates average word length
- Identifies the most frequently used word

## Technologies Used
- Python
- Regular Expressions (`re`)
- Collections (`Counter`)

## How It Works
The program accepts a paragraph from the user and processes the text to calculate different statistics. It uses regular expressions to identify words and sentences and Counter to determine word frequency.

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run:

```bash
python text_analyzer.py
```

4. Enter a paragraph when prompted.

## Example

Input:

Python is easy to learn. Python is powerful.

Output:

- Total words: 8
- Total characters: 43
- Total sentences: 2
- Most frequent word: python
